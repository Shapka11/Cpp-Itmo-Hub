## Архитектура ЭВМ (Схемы)

| Лабораторная | Описание |
| :--- | :--- |
| **Квадратный корень (half precision)** | Итерационное вычисление корня в Logisim и Verilog. |
| **Числа с фиксированной точкой** | Арифметические операции с фиксированной точкой (C++), дополнение до 2, округления. |

### Описание (Lab: Fixed Point)
- **Цель:** Написание программы для арифметических действий с дробными числами без использования типов с плавающей точкой.
- **Инструментарий:** C++23.
- **Особенности:** Поддержка различных типов округления, работа с 16-ричным представлением, реализация модулярной арифметики.

## Краткое описание

*   **Sandpile Model:** Реализация клеточного автомата. Сохранение итераций в формате `.bmp`.
*   **ArgParser:** Библиотека для парсинга аргументов командной строки (поддержка string, int, bool, GoogleTest).
*   **Route Searcher:** Поиск маршрутов через Yandex API, кэширование и работа с HTTP-запросами.
*   **Adapters & Streams:** Библиотека функциональных адаптеров для потоковой обработки данных.
*   **Task Scheduler:** Система планирования задач с графом зависимостей и Future-результатами.
